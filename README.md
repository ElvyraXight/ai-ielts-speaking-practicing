# AI IELTS Speaking

一个本地运行的雅思口语练习 App：Streamlit 界面 + Ollama（默认 `qwen2.5:7b`）/ DeepSeek API + Whisper 语音识别 + edge-tts 朗读。

> 本项目 fork 自 [LegendZDY/AI-IELTS-Speaking](https://github.com/LegendZDY/AI-IELTS-Speaking)（MIT License，Copyright © 2024 De Ying Zhang）。
> 当前仓库在此基础上做了大量个人化改造：模块拆分、按天快照备份、角色永久记忆、测试等。
> 原始许可证见 [LICENSE](LICENSE)，第三方素材说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 功能

| 页面 | 能做什么 |
| --- | --- |
| 入口 | 总览页：今天的打卡（背单词 + 表达复习 + 课程计划）和各模式入口 |
| 严肃话题（全真模拟） | AI 考官按雅思流程提问和追问；实时给语法纠错、润色和 Band 8 参考回答；支持麦克风输入和朗读 |
| 自由聊天 | 自定义聊天对象人设，日常闲聊；附语法、润色、地道表达建议 |
| 讲个故事（Part 2） | 生成标准 Cue Card；打字或录音讲故事；时态语法纠错、Band 7 改写答案、Band 8 参考范文；可朗读 |
| 背单词 | 7,298 个雅思词库；按目标日期规划每日词量、记住起始难度；今日学习 / 只复习 / 巩固；看词选义、看义选词、例句填空拼写；可浏览已背过的词 |
| AI 老师 | 对话式雅思老师；所有回复由主模型统一说出来，后台老师只给建议；备课本是唯一候选池；计划第一个点取最早加入，之后取最新；直接发单词 / 词组 / 句子会逐条讲解并生成发音；改答案、讲结构、模拟 Part 3 追问 |
| 笔记本 | 单词 / 词组 + 表达库 + 长文本笔记；单词自动补全、按词光逻辑复习，表达按间隔重复复习，长文本按日期归档、标题可自动生成 |
| AI闲聊 | 温柔、绅士、风趣、知识渊博的聊天对象；跨会话记忆；不做诊疗/指导记录 |
| 猫娘小屋 | 角色扮演聊天（英文回复，中文提问会自动翻译） |
| 心理咨询 | 心理咨询师角色对话 |
| 学业导师 | 电子信息 / 论文方向导师角色对话 |

首页按 **练习 / 工具 / 娱乐** 三个栏目组织：练习是三种口语训练加背单词，工具是 AI 老师和笔记本，娱乐是 AI闲聊、猫娘和两位导师。

所有聊天 / 提交框都支持 **Ctrl+Enter** 直接发送，不用先点按钮；逗号、回车换行不受影响。

## 运行

1. 安装 Python 3.12+，并在系统里安装 **ffmpeg**（Whisper 转写需要）。
2. 安装依赖：
   ```powershell
   pip install -r requirements.lock.txt
   ```
   lock 文件是当前验证过能跑的完整版本（含间接依赖）。只想要大版本、不在乎可复现时可以退回 `pip install -r requirements.txt`。
3. 选择模型：
   - **在线（推荐）**：在 `config/.env.local` 填 `DEEPSEEK_API_KEY`，见下方「使用 DeepSeek 在线 API」。
   - **本地**：安装并启动 [Ollama](https://ollama.com)，然后 `ollama pull qwen2.5:7b`。
4. 启动 App：
   - **日常用**：双击 `AI IELTS Speaking`（紫色 IELTS 图标）。它在后台启动、自动打开浏览器，不弹命令行窗口；服务已经在跑时只打开浏览器。
   - 第一次在新机器上用，先跑一次 `tools\make-shortcut.ps1` 生成三个快捷方式（`.lnk` 里存的是绝对路径，所以没进仓库）：
     `AI IELTS Speaking`（启动）、`Stop App`（停止）、`Backup Data`（备份）。
   - 停止后台服务：双击 `Stop App`。
   - 用快捷方式而不是 `.bat`：Windows 对 `.bat` 会弹「未知发布者」的安全警告，快捷方式启动的是系统自带的 PowerShell，不会弹。
   - 调试用：双击 `start.bat`，有命令行窗口和实时日志；隐藏启动的日志在 `logs\app.out.log` 和 `logs\app.err.log`。
   - 如果 8501 被别的程序占着，启动器会提示端口冲突，而不是"启动成功"却打开别人的页面；也可以用 `tools\launch.ps1 -Port 8600 -Test` 换端口试。
   - **改了 `utils\` 下的模块之后要重启 App**（Stop App → 再启动）。Streamlit 的热重载只重新执行页面脚本，不会重新 import 已经加载的 `utils` 模块，否则页面会报 `ImportError: cannot import name ...`。
5. 浏览器会自动打开 http://localhost:8501 ；没弹出来就手动访问。

## 模型配置

配置文件是 `config/.env`（本地密钥建议放 `config/.env.local`，已被 `.gitignore` 忽略）。

```ini
# auto: 配了 DEEPSEEK_API_KEY 就用 DeepSeek，否则用 Ollama
LLM_PROVIDER=auto

DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash

OLLAMA_URL=http://localhost:11434/api/generate
OLLAMA_MODEL=qwen2.5:7b
```

说明：

- **全站页面**（严肃话题、自由聊天、讲个故事、AI 老师、娱乐小屋）统一使用上面的配置。
- 配了 `DEEPSEEK_API_KEY` 后，所有页面都走 DeepSeek 在线 API；没有 Key 时回退本地 Ollama。
- 修改 `.env` 后需要重启 App。
- 各功能页顶部会显示当前模型，例如 `🤖 当前模型：DeepSeek · deepseek-flash`；工作台不显示这行，直接看右上角的模型下拉框。

### 手动切换模型

主页右上角的「模型」下拉框可以随时切换：

- `DeepSeek · deepseek-flash`：默认，便宜、快
- `DeepSeek · deepseek-v4-pro`：更强，单价更高
- `Ollama · ...`：本机已安装的 Ollama 模型

选择保存在当前浏览器会话里，切换后所有页面立即使用新模型；没有配置 DeepSeek Key 时只显示本地 Ollama 选项。

### 使用 DeepSeek 在线 API

1. 打开 <https://platform.deepseek.com/>，登录并充值（API 按量计费，先充少量即可）。
2. 左侧「API keys」→ 创建 API key，复制 `sk-...`（只显示一次）。
3. 打开 `config/.env.local`，填：
   ```ini
   DEEPSEEK_API_KEY=sk-你的key
   ```
4. 重启 App（关闭 Streamlit 窗口后重新双击 `start.bat`）。
5. 页面顶部显示 `🤖 当前模型：DeepSeek · deepseek-flash` 即生效。

## Token 与费用（大致）

`deepseek-flash`，thinking 已关闭。下面是各操作**每次触发的模型调用次数**：

| 操作 | 调用次数 | 是否阻塞等待 | 说明 |
|---|---:|---|---|
| Part 2 判题 | 2 | 是 | 点评 + Band 7 改写在一次调用里，范文另一次，两者并行；改写不足 140 词会补一次扩写（偶尔 3 次） |
| 严肃话题一轮 | 2 | 是 | 考官回复 + 纠错/润色 |
| 自由聊天一轮 | 2 | 是 | 朋友回复 + 纠错，两者并行 |
| AI 老师一轮 | 2–3 | 是 | 后台老师 1 次 + 主模型表达 1 次；有计划点时每条可见回复再调 1 次计划裁判 |
| 训练一轮（命中裁判关键词） | 3 | 是 | 陪练 1 次 + 主模型表达 1 次 + 计划完成裁判 1 次 |
| 词典讲解 | 2 | 是 | 词典内容 1 次 + 主模型开场 1 次；发音另算 |
| 老师开课备课 | 1 | 是 | 手动生成 / 每天首次打开且计划已完成时；0 点和未完成计划不重复调用 |
| 娱乐闲聊一轮（英文） | 2 | 否 | 回复之后，记忆提取在后台跑 |
| 娱乐闲聊一轮（中文） | 2 | 否 | 翻译和回复在同一次调用里返回，不再多发一次翻译请求 |
| 心理咨询 / 学业导师一轮 | 3 | 否 | 多一次会话笔记；同一会话的笔记更新会自动合并，不排队 |

- **记忆和笔记在后台写**：回复和语音先给你，`update_memory` / `update_session_note` 在后台线程完成，失败只记日志。
- **陪练记忆只写两次**：一课只在开始和结束时各更新「英语学习档案」，中间重说不重复调用；「关于你」与它分开，在后台更新。
- **中文回复只花一次调用**：以前是"回复 + 翻译"两次同步请求，现在同一次调用返回 `reply` 和 `reply_zh`。
- **不再误判语言**：短英文（`ok`、`sure`）不会再被当成中文去翻译。
- **笔记输入变短**：只取最近 12 条、每条 350 字（以前 20 条 × 500 字），每轮省下约一半输入 token。
- **请求更稳**：429/5xx 按 `Retry-After` 重试一次；401/403 不重试，直接走兜底，不会白等。
- 每次 DeepSeek 调用的真实 token 记录在 `utils/llm.py` 的 `usage_log()` 里，排查费用时可以直接看。

## 笔记本

- 入口：左侧「工具 → 笔记本」，或首页的「📓 笔记本（单词 / 表达 / 长文本）」。
- 顶部三个 tab：单词 / 词组、表达、长文本笔记。
- 首页「今天」里的「去巩固单词/词组」是这里的快捷入口：跳到「单词 / 词组 → 复习」，小字里显示**今天已经巩固完的条数**（按最后一次复习日期统计）；没有到期条目时按钮置灰。
- 各练习页（严肃话题、自由聊天、讲个故事、AI 老师）侧边栏都有「➕ 加入笔记本」，可选择添加「单词 / 词组」「表达」或「长文本笔记」；长文本同样按日期归档，标题可留空自动生成。
- 添加单词 / 词组时只需要填单词和可选的例句；意思、词性和标签会自动补全。
- 手动例句可以一行一个，按义项顺序对应；只填一句时会自动识别它属于哪个义项，其余义项补齐例句。
- 每个中文义项都会自动配一条 IELTS 水平的英文例句，按义项顺序显示；例句不提供中文翻译。
- 新增时如果没填中文意思 / 标签，会自动补全：
  - 意思带词性前缀：`n.` `v.` `a.` `ad.` `phr.`；
  - 同一词性下真正不同的意思用 `/` 分开，近义词只保留最常用的一个；
  - 自动按雅思分类打标签。
- 默认按语义相关度排序：相关的词相邻，越新越靠前；不再显示「程度描述」这类分类标签。
- 默认只显示单词 / 词组；展开后逐条显示义项和对应例句。点「✏️ 修改」才进入编辑，来源不可修改。
- 每条笔记都可以手动改翻译、标签；侧边栏有「补全缺失的翻译 / 标签 / 例句」处理旧笔记。
- 单词视图分「复习 / 单词表」两栏，默认进「复习」：和背单词同一套词光逻辑，看词选义 → 看义选词 → 例句填空拼写，答完自评「忘了 / 模糊 / 记得 / 太简单」，按 1 → 3 → 间隔 × 难度排下一次。
- 「单词表」里支持搜索、标签筛选、修改、删除和导出 JSON。
- 「全部笔记」用正常字号加粗显示，不使用开关。
- 数据保存在 `data/notebook.json`，已加入 `.gitignore`；重启 App 不会丢。

### 长文本笔记

- 在「笔记本」顶部切换到「长文本笔记」，和单词 / 词组并列。
- 每篇就是一大块文本，适合存语法知识、范文、阅读摘录。
- 按日期归档：日期自动记录为当天，不需要手填；同一天的多篇归在同一天下面。
- 标题可以自己填，也可以留空；留空保存时由 AI 自动总结一个中文标题。
- 平时只读展示，保留原文换行；点「✏️ 修改」才展开编辑表单，编辑时隐藏正文。
- 每篇都可以修改正文和标题，也可以删除；支持导出 JSON。
- 数据保存在 `data/long_notes.json`，已加入 `.gitignore`。

### 表达库

- 在「笔记本」顶部切到「表达」。这里记的不是单词，而是「想表达的意思 → 地道说法」这一对。
- 入口：笔记本的「表达」tab，或各练习页侧边栏的「➕ 加入笔记本 → 表达」。
- 一条表达包含：中文意图（必填）、地道说法（必填）、你当时的说法（可选）。
- 场景不用手填：保存时自动记录当前上下文（Part 2 的完整题卡、考官上一句追问、聊天人设或 AI 老师当前题卡）。
- 复习是产出式的：只给中文意图，先自己把英文说出来或打出来，再点「显示地道说法」对答案，然后自评「没印象 / 差一点 / 说对了」。
- 和「单词 / 词组」一样分「复习 / 表达表」两个视图，默认进复习；「表达表」里才有新增、搜索、排序和列表。
- 间隔重复：说对了按 1 → 3 → 7 → 14 → 28 天拉长；差一点明天再来；没印象当天算到期，可以马上再练一轮。
- 「表达表」顶部显示待复习 / 总条数 / 已掌握；「已掌握」指复习间隔达到 21 天以上。
- 列表里每条和单词卡片同一套格式：展开看地道说法、当时的说法、场景、来源和复习状态，底部是「添加 / 更新」时间和「✏️ 修改」「🗑 删除」两个小按钮。
- 支持搜索、修改、删除、导出 JSON。
- 数据保存在 `data/expressions.json`（已 gitignore）。
- 设计意图：说不出来就等于没学会，所以没有「只看一眼」的复习方式；也不自动抽取候选，避免生成一堆没时间整理的内容。

## 背单词

- 入口：左侧「练习 → 背单词」，或首页的「📚 背单词」。
- 词库：Word Atlas 的 **7,298 个雅思词条**（CEFR A1–C2，19 个话题），每个词含英/美音标、1–3 个中英义项、两条例句（附中文）、搭配、词族、近反义和一条中文提示。
- 今日队列 = 到期复习 + 每日新词（默认 10 个，侧边栏可在 5–50 之间调）；新词按词库由易到难取。
- **目标日期**：在侧边栏打开「按目标日期规划」，填考试日期，会按还没背的词数反推「每天要学几个」，点一下即可应用到每日新词。
- **记住起始难度和话题**：起始难度（只学这一级和更难的词）与话题筛选会保存在进度里，下次打开不用重选。
- **三种练习**：今日学习（复习 + 新词）、只复习到期、巩固已学（从学过的词里挑最薄弱的 10 个打乱）。
- 首页「今天」里的「去背单词」直接进入这一页；旁边的「去巩固单词/词组」是笔记本单词表的复习，不在这页。
- **已背过的词**：顶部切到「已背过」，可按单词 / 中文搜索、按学习中 / 已掌握筛选，展开看完整词卡和复习记录，也可以把某个词移出已背记录。
- 三阶段主动回忆：**看词选义 → 看义选词 → 例句填空拼写**。答完显示完整词卡，可点「🔊 听发音」（edge-tts 实时生成）。
- 自评「忘了 / 模糊 / 记得 / 太简单」决定下次时间：忘了当天再练，记得按 1 → 3 → 间隔 × 难度递增，最长 180 天。
- 进度保存在 `data/word_progress.json`（已 gitignore），每次写入前自动留快照。
- 词库来自 [Word Atlas](https://github.com/designfuchen/word-atlas)，内容按 **CC BY 4.0** 使用（署名：Word Atlas contributors）。本 App 只取词表文字字段，未使用其插画与录音；发音由 edge-tts 生成。完整许可见 `assets/word-atlas-LICENSE.txt`。

## AI 老师逐条讲解

- 直接发纯英文的单词、词组或句子，不加中文说明，老师会自动切到「词典讲解」。
- 一行一个、逗号分隔或空格分隔的多个词会拆成多条；完整词组或句子保持为一条。
- 每条显示音标、词性、中文翻译、用法扩展、常见搭配和例句，旁边有 `🔊` 按钮，点一下播放发音。
- 普通提问、让老师改答案等仍然走原来的雅思老师人设。
- 老师不会每轮都以问题结尾：多数回复停在建议、例子或一句指令；只有确实需要你回答时才问一个，不会为了“让你多说”硬加问题。

### 主模型表达层

- 学生看到的每一句话由主模型 [utils/TutorLead.py](utils/TutorLead.py) 统一说出来；后台的 Tutor / 陪练 / 词典只提供内部 brief，不再直接对学生说话。
- 主模型先回应学生刚说的内容，再决定怎么教；它保留 brief 里的纠错、例句、目标词和事实，不新增错误，也不会把内部术语暴露出来。
- 它每轮读完整对话 + 「关于你」记忆 + 「英语学习档案」；侧边栏对应两个记忆区。
- 如果 brief 里的练习此刻不合适，主模型可以设置 `keep_practice=false`，这一轮就不开训练。
- 后台老师仍然负责出题、判分、维护备课本和本课计划；主模型只负责“怎么说才像正常人在说话”。

### 对话与陪练

- **AI 老师页是文字对话**：老师看不到、也听不到你的声音，不能评价发音、重音、语调、语速或口音。她只会让你“把整句再打一遍”。页头也会标明这一点。
- 普通聊天、打招呼、问考试流程、问词义、问区别，都不会自动进入训练。
- 不再有「开始训练」按钮，也没有「回复开始」的确认步骤。你主动说「我想练 / 陪我练 / 考我」后直接进入训练。自然说法「我们再稍微练会吧」「我们开始训练吧」也会被识别。
- 训练已经开始后，再说「开始」不会把训练关掉，只会提醒你直接回答当前问题。
- 训练中点名另一个计划点（例如「let's start with I can hear you very clearly today」）会直接切到那个点，不会退出训练。
- 训练还要求本课计划里至少有一个未打勾的点；计划全部完成后不能训练，需要更新计划。
- 训练中如果你问流程/区别/词义，或说“不练了 / 换个话题”，她会先退出这一句回答你。
- 没有单独的「练习模式」：训练时页面顶部只多一行小字「训练中」，输入框灰字会变成「把你这句英文完整打出来，老师在等你的回答…」。
- 练习式回答：先评价，再把这句话的要求一次讲清（2–4 条）；之后只针对没满足的那条说改法，不直接给成品句。
- 短回复（`ok`、`sounds good`、`I think so`）按“说话”处理，不弹词典卡；单独发单词/词组才走词典讲解。

### 计划完成裁判

- 训练时另有一个**独立裁判模型**，只做一件事：看老师最终发出来的回复，决定本课计划哪个点可以打勾。
- 现在不只训练：老师**每条可见消息**都会过一遍轻量裁判，识别当前在练哪个计划点。
- 只要老师从上一个点切到新点，就把上一个点打勾；但会先检查你在两条老师消息之间发的那句，是否真的回答了上一条老师问的点。没回答、换话题或只问别的，不会打勾。
- 裁判看：
  - 老师当前这条可见回复；
  - 上一条老师回复；
  - 上一个正在练的点；
  - 当前计划里还没打勾的点。
- 判定规则：
  - 老师开始问下一个点 → 上一个点通过；
  - 老师开始综合练习，明确用到多个点 → 这些点都通过；
  - 老师还在改同一个点，或只说“不错/很好” → 不打勾。
- 普通聊天和训练都会检测，所以即使没点「开始训练」，老师从 tug 切到 lullaby 也会把 tug 打勾。
- 一旦识别到某个点完成、并且计划里还有未完成点，会自动进入训练状态，下一条消息直接按训练回答处理。
- 裁判和老师用同一个模型，但独立 prompt、独立请求；以后可以换。
- 裁判把计划点全部打勾后，自动结束训练并提示「本课计划已完成」。
- 陪练自己的 `status` 仍用于“这轮要不要继续教”，但不再直接决定计划点。

### 本课计划

- 计划只从**备课本**选点，不再单独读笔记本/表达库/弱词。
- 第一个点固定找备课本里**加入最早**的合格点；第二个点起恢复按加入时间从新到旧选。
  - 上个计划出现过的点：0 个；
  - 上上个计划：最多 1 个；
  - 上上上个计划：最多 2 个；
  - 一个点只按最近一次出现的计划算配额。
- 自动计划最多 3 个，可以不足 3 个，也可以是 0 个。
- 你明确要练的点可以追加进计划，不受配额限制；计划总上限 10 个，满了直接拒绝。
- 只有计划里所有点都打勾，计划才算完成；有点没打勾就一直不变。
- 每天第一次打开老师页：如果计划已完成、备课本里还有点，自动重新备课；0 点计划不自动重试。
- 侧边栏「📋 本课计划」显示进度；全部完成后可手动「更新计划」。
- 计划展开后有「🔍 强制检测是否完成」：点一次会把本场全部聊天交给裁判，检查哪些计划点其实已经完成；适合裁判漏判时手动补。超长聊天只取最近 120 条。 
- 计划在 `data/tutor_plan.json`。

### 今天的课程计划打卡

- 首页「今天」新增第三项「📋 课程计划」：
  - 还没有计划 → 「还没有课程计划」；
  - 有未完成点 → 「待完成 X 个」；
  - 今天完成了 → 「✅ 今天已完成」；
  - 计划是之前完成的 → 「计划已完成，去更新」，去老师页会自动备下一课。
- 点「去上课」直接进雅思口语老师页。
- 完成标准：本课计划里所有点都打勾，并且至少有一个点是在今天打勾的。
- 首页还会显示「🎉 今日累计完成 X 个点」：即使今天重新备过课、换了新计划，之前完成的点也会累计，不会被清零。

### 备课本

- 备课本是**唯一候选池**，侧边栏全部显示（最多 200 条，可滚动）。
- 来源：
  - 背单词里的弱词；
  - 笔记本里的单词/词组/表达；
  - 表达库；
  - 你从「待整理知识点」里手动加入的错误。
- 每个词/条目只进一次；同一个词从弱词和笔记本两个来源来也只留一条，两个来源都算“已进入过”。
- 不做模糊/语义去重，不做高相关判断。
- 上限 200，满了删加入时间最久远的；当前计划里的点不删。
- 你说「我想练 X」时，先查完全一样的条目；没有就确认一个概括，再同时加入备课本和计划。
- 如果 X 已经在备课本里，确认卡片只显示「加入课程计划」，直接加进当前计划，不会重复写备课本。
- 数据在 `data/prep_book.json`。

### 待整理知识点

- 来源有两处：
  - 普通聊天里老师明确指出的错误；
  - 陪练判分时返回的 `new_issues`。
- 不自动进备课本，也不自动算错；先放进「待整理知识点」，由你决定。
- 像猫娘记忆一样合并同类错误、累计次数、按最熟悉排序。
- 每条两个按钮：
  - **加入备课本**：写进备课本，并从错误列表删除；
  - **删除**：只从错误列表删除。
- 数据在 `data/tutor_errors.json`。

### 关于你

- 记录你这个人、我们的关系、你对我说过的事、你在意什么；不记录英语水平。
- 结构像猫娘记忆：事实 + 提到次数 + 固定/淡忘逻辑。
- 每轮对话后台更新；主模型每轮读取。
- 你说「记住……」时，会按内容分流：关于你这个人/关系/名字的进「关于你」；关于英语水平/错误/练法的进「英语学习档案」。
- 侧边栏「关于你」可以查看、固定、删除、清空。
- 旧对话摘要数据已清空，从新开始。

### 英语学习档案

- 记录你的英语水平、已掌握、待巩固、有效练法。最近练习只在内部用于给建议，侧边栏不再显示「最近」。
- 即使不训练，你问“我的弱点是什么”“该怎么练”，她也能基于这份档案回答。
- 侧边栏「英语学习档案」可以查看和清空。
- 数据在 `data/teacher_memory.json`；旧数据已清空，功能保留。

## 聊天记录

- 7 个聊天页各自有一份本地记录：
  - 雅思口语老师、自由聊天、解压小屋、AI 闲聊、心理咨询室、学业导师、AI 雅思考官。
- 消息保存在 `data/chat_history.json`（已 gitignore），刷新页面或关掉浏览器再回来会恢复。
- 消息和对应设置会恢复：
  - 心理咨询/学业导师的 note session 跟着记录恢复，重新开始才开新 session；
  - 自由聊天的自定义人设也会恢复；
  - 雅思老师训练中的输入状态、当前训练问题也会恢复，刷新后不用重新开始。
- 每页最多保留最近 300 条，互不覆盖。
- 每个聊天页侧边栏最底部有「🔄 重新开始聊天」：
  - 先二次确认；
  - 只清当前页的消息和临时状态；
  - 不清「关于你」「英语学习档案」「备课本」「待整理知识点」「本课计划」；
  - 心理咨询/学业导师会开新的 session，旧诊疗/指导笔记保留；
  - 自由聊天的自定义人设保留。
- 清空时仍会留下每日自动备份，不额外删除 `data/backups/`。

## 随手查

- 侧边栏背景音下面常驻一个输入框，任何页面都能用；和 AI 老师页一样是 `st.chat_input`，**Enter 直接发送**。
- 输入英文 → 弹窗给中文翻译；输入中文 → 一行直译 + 3-5 个英文说法（每个带一句语域说明）。
- 结果只在内存里，不落盘；关掉弹窗就没了。
- 保存按类型走：**单词 → 单词表，句子 → 表达库，词组**给你「单词表 / 表达库」两个按钮自己选。
- 存单词表是快速保存：只写词、释义和备注，不再调模型补全例句/标签。

## 娱乐角色的长期记忆

- AI闲聊、猫娘、心理咨询师、学业导师各有一份独立记忆，保存在 `data/memories.json`（已 gitignore）。
- 每次聊天仍从开场白开始，但会把重要信息带进 prompt：你的身份、城市、工作/学习、偏好、关系、目标和共同经历。
- **只增不减**：每轮对话后模型只报告「这轮新增了什么 / 哪条又被提到 / 哪条要固化」，合并由本地完成。以前是让模型重写整份清单，它某次少写一条，那条就真没了。
- **反复提到就固化**：同一件事被提到 3 次自动变成永久记忆；你说「记住……」「别再忘」「我说过很多次」这类话时，这一轮提取到的事实立刻固化。
- **永久记忆不会淡忘**：注入 prompt 时单独成段，并明确要求「不要反问、不要自相矛盾」。普通记忆 60 天没再提、且只提过一次，才会淡忘。
- 侧边栏的「记忆」里分永久 / 普通两栏，每条可以手动 📌 钉成永久、🔓 取消；普通记忆会显示「提到 N 次」。删除只保留「清空这个角色的记忆」这一个入口。
- 旧版本的记忆会自动迁移成永久记忆，升级不会丢东西。
- 四个角色的记忆互相独立：猫娘不会知道你和咨询师聊过什么。
- **记忆提取在后台跑**：回复和语音先给你，写记忆的请求在后台线程完成，不占你等回复的时间；连续快发几条也不会互相覆盖（合并时按事实原文匹配，不按下标）。

## 诊疗笔记 / 指导记录

- 心理咨询师每次会话生成一份带日期的「诊疗笔记」；学业导师生成一份「指导记录」。
- 和长期记忆完全独立：只记录这一次聊了什么、结果和建议，不会写进记忆，也不会被记忆影响。
- 每次新开会话生成一条；同一会话里继续聊会更新同一条，日期取会话开始那天。
- 更新在后台进行；如果上一轮还没写完又聊了一轮，只保留最新的那份转录继续写，不会排成一队。
- 保存在 `data/session_notes.json`（已 gitignore）。
- 在侧边栏「记忆」下方，默认收起；点开「诊疗笔记 / 指导记录」后只看到日期列表，再点某个日期才展开那一条的内容，避免记录多了以后整页拉得很长。

## 数据备份

- 所有本地 JSON（笔记本、长文本、表达库、背单词进度、备课本、待整理知识点、本课计划、每日完成点、关于你、英语学习档案、各页聊天记录、背景音设置、角色记忆、诊疗记录）在每次写入前都会先留一份快照到 `data/backups/`。
- 每个文件**每天只留第一份**快照，命名如 `notebook-20261028.json`，保留最近 30 天。
  以前是"最近 20 份"，但背单词每答一个词就写一次，20 份只够几分钟，等于没有备份。
- 内容没有变化时不会写入，也不会生成新快照。
- 如果某个文件已经损坏（不是合法 JSON），写入前会先把它复制到 `data/backups/corrupt/` 再写新数据，原始内容不会被覆盖。
- 恢复：把想要的那份复制回 `data/` 下的原名（例如 `data/expressions.json`），重启 App 即可。
- `data/backups/` 已加入 `.gitignore`。

### 备份到私有仓库（可选）

上面的快照只在同一块硬盘上，防不了硬盘故障。想要异地备份，可以再准备一个**单独的私有仓库**：

1. 在 GitHub 上新建一个空私有仓库（例如 `ai-ielts-speaking-data`，不要勾 README）。
2. 把这个仓库的 deploy key 配好（只对数据仓库生效，私钥放在 `.ssh-data/`，已 gitignore）。
3. 双击 `Backup Data`（跑完窗口会留着让你看结果），或命令行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\sync-data.ps1
   ```
   第一次会把仓库克隆到 `.data-repo/`，之后每次只同步 `data/*.json` 并提交推送。
4. 恢复：把仓库里的 `data/*.json` 复制回项目 `data/`。

注意：私密仓库不等于加密，这些内容会以明文留在 GitHub 的提交历史里；仓库路径可以在脚本参数 `-Remote` 里改。

- 没有本地文件时，回退到仓库自带的 6 段 CC0 现场录音：雨声、海浪、森林鸟鸣、溪流、风声、夜虫；来源与授权见 `static/ambient/SOURCES.md`。
- 音频会解码成 AudioBuffer 后无缝循环，切歌有淡入淡出；选择和音量保存在 `data/ambient.json`，下次打开继续用。
- 播放器挂在页面外层而不是页面内容里，所以**切换页面、切换练习不会中断**。
- 想换音色：把 mp3 放进 `static/ambient-local/`，文件名对应 id（`rain.mp3`、`fire.mp3`……）即可，不用改代码。
- 浏览器通常会拦截带声音的自动播放：第一次打开如果没声音，点一下页面任意位置，或点右下角的「🔊 点击开启背景音」。

## 语音

- 识别：优先用 `faster-whisper`（CTranslate2，CPU 上比 openai-whisper 快），按需加载、全站单例；缺少依赖或模型加载失败时自动回退 `openai-whisper`，语音功能不会因此失效。
- 模型默认 `base`，可用环境变量 `WHISPER_MODEL` 换成 `small` 等；`WHISPER_COMPUTE_TYPE` 控制精度（默认 `int8`）。
- 如果项目里存在 `models/faster-whisper-base`，会直接使用本地模型，不再联网下载。
- 朗读：`edge-tts`。
  - 雅思练习、AI 老师、日常闲聊：英式男声 `en-GB-RyanNeural`
  - 学业导师：英式男声 `en-GB-ThomasNeural`
  - 猫娘：英式童声 `en-GB-MaisieNeural`（音色最娇小；想更成熟可换 `en-GB-LibbyNeural`）
  - 心理咨询：`en-US-AriaNeural`
- 生成的 mp3 **只保留当天**：每次合成都会产生新文件，清理放在 `utils/tts.py` 里按天执行，不管从快捷方式、`start.bat` 还是命令行启动都生效。跨天会话里昨天的播放器会失效，重新点一下即可。
- 合成中断不会留下 0 字节文件：先写 `.part` 再改名，失败时删掉残片；页面也只把非空文件交给播放器。
- 日志：`LOG_LEVEL=DEBUG` 可以看到模型加载、转写、LLM 调用等细节（默认 `INFO`，输出到启动 App 的终端）。
