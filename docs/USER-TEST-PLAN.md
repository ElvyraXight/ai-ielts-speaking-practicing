# 用户验收手册：把 App 当成产品点一遍

> 目的：自动化测试保证“逻辑没坏”，这份手册负责自动化测不到的部分——
> 模型输出质量、真实语音链路、浏览器行为、排版和文案。
>
> 你负责操作；我负责根据编号定位问题。报问题时给编号、输入、看到什么、期望什么即可。

## 0. 怎么用这份文档

1. 先看第 1 节，留一份可回滚的数据备份。
2. 先跑第 2 节的「10 分钟冒烟」；有硬故障就停下，不用继续。
3. 再按第 3 节的顺序测。顺序不是随意的：**前面的操作会给后面喂数据**
   （背单词 → 备课本 → 老师带练 → 工作台打卡）。
4. 每个用例有编号，例如 `T-05`。报问题时用编号，不用复述整条路径。
5. 第 7 节列了已知边界，看到这些现象不要当 bug 记。

## 1. 测试前

### 1.1 环境

| 项 | 现状 | 怎么确认 |
| --- | --- | --- |
| App | <http://127.0.0.1:8501>，只绑 `127.0.0.1` | 浏览器能进「今天」工作台 |
| 模型 | DeepSeek 在线，或本地 Ollama | 页面顶部「🤖 当前模型：…」 |
| 语音识别 | 本地 faster-whisper（可回退 openai-whisper） | 录音后出现转写文字 |
| 朗读 | edge-tts 在线合成，mp3 落 `audio_records/` | 消息下方出现播放器 |
| ffmpeg | 已加入 PATH | 录音转写能跑通 |
| 数据 | `data/` 下 15 个 JSON，快照在 `data/backups/` | 当天第一次改动会多一份快照 |

> 所有 AI 功能都要真调模型；老师一轮普通对话约 3 次调用，训练回合更多。
> 慢是正常的，不是卡死。

### 1.2 先留一份可回滚的底

测试会改真实数据（背单词进度、计划点、笔记、长期记忆都是永久的）。开始前先备份：

```powershell
$stamp = Get-Date -Format 'yyyyMMdd-HHmm'
$dest = "data\backups\manual-before-uat-$stamp"
New-Item -ItemType Directory -Force $dest | Out-Null
Copy-Item data\*.json $dest
```

回滚：

```powershell
# 先停 App，否则内存里的旧状态会在下次写入时覆盖还原
powershell -ExecutionPolicy Bypass -File tools\stop-app.ps1
Copy-Item "data\backups\manual-before-uat-<时间>\*.json" data\ -Force
```

以下动作单独测，不要和别的用例混在一起：更新计划、重新开始聊天/考试、删除笔记、
移出已背过、完成计划点、清空记忆。

### 1.3 测试纪律

- 一次只动一个变量：先记下操作前的样子，再操作，再看操作后的样子。
- 页面报红字先截图，再看 `logs\app.err.log` 最后几行。
- 每个涉及持久化的页面，刷新前后各看一次：**刷新会丢什么、不会丢什么**是重点。
- 不要用两个标签页测“并发正确性”；这个 App 是单用户设计。

## 2. 10 分钟冒烟

| # | 做什么 | 通过标准 |
| --- | --- | --- |
| 1 | 打开工作台 | 能看到「今天」三行打卡；练习 4 个、工具 3 个、娱乐 4 个按钮都能点 |
| 2 | 任选一个 AI 页发一句话 | 能拿到回复；练习三页要按「提交并获取反馈」，其余页回车发送 |
| 3 | 背单词点「开始今日学习」并答一题 | 能进入答题；四档评分能进入下一题 |
| 4 | 笔记本能打开、能新增一条 | 列表正常；新增后能看到条目 |
| 5 | 侧栏随手查一个词 | 弹窗有内容；不点保存不会写库 |
| 6 | 刷新页面 | 聊天记录还在；侧栏「重新开始」会先弹确认框 |

任何一条硬失败（白屏、报错、按钮无反应、数据丢失），先停下报告，不要继续往下测。

## 3. 建议顺序

| # | 场景 | 覆盖页面 | 为什么排这里 |
| --- | --- | --- | --- |
| 1 | 第一次打开，什么都没有（可选） | 工作台 · 背单词 | 看空数据时的文案和入口 |
| 2 | 设考试日期 + 背一轮单词 | 背单词 | 后续打卡、备课本的数据来源 |
| 3 | 随便聊两句 | 自由聊天 | 最简单的 AI 页，先确认模型通 |
| 4 | 模拟考官问三轮 | 严肃话题 | 三栏反馈、录音、朗读 |
| 5 | 抽一张 Cue Card 讲一段 | 讲个故事 | 题卡生成、评估、范文、草稿持久化 |
| 6 | 把说错的存进笔记本，再复习 | 笔记本 | 三库 + 复习 + 导出 |
| 7 | 在任意页随手查一个词 | 侧栏随手查 | 全站能力，不落盘 |
| 8 | 让老师备一节课并带练 | 雅思老师 | 最复杂链路：备课本 → 计划 → 裁判 → 打卡 |
| 9 | 问一个语法问题 | 查资料 | 普通对话 + 随手记 |
| 10 | 四个角色各聊两句 | 娱乐四页 | 人设、长期记忆、会话笔记 |
| 11 | 全站横切 | 所有页 | 录音、朗读、背景音、刷新、多标签 |

## 5. 逐页用例

### 5.1 全站骨架（G）

| 编号 | 操作 | 预期 | 边界 |
| --- | --- | --- | --- |
| G-01 | 双击快捷方式 / 打开 <http://127.0.0.1:8501> | 落在「今天」工作台；右上角有模型和背景音；侧栏有音量和随手查 | 打不开先刷新；还不行看 `logs\app.err.log` |
| G-02 | 进任意子页，看侧栏顶部 | 出现「← 工作台」；点一下回工作台 | 工作台上这个位置是空的（保留槽位） |
| G-03 | 工作台右上角切换模型，进一个 AI 页发消息 | 页面顶部模型跟着变；回复正常；重启后仍是这个模型 | Ollama 需要本机服务在跑；DeepSeek 需要 key/网络 |
| G-04 | 选背景音、调音量、切页面再回来 | 声音连续；换页不重启播放；音量和选择记住 | 浏览器拦截自动播放时显示「🔊 点击开启背景音」 |
| G-05 | 侧栏输入英文词，回车 | 弹「随手查」：按词性列义项、例句、例句中文；底部有保存按钮 | 结果不落盘，关掉就没了；同词再查走缓存 |
| G-06 | 侧栏输入中文，回车 | 先给直译，再给 3–5 个地道说法；每条带中文意图 | 没有中文释义的条目会提示暂不能存表达库 |
| G-07 | 在弹窗里点「存单词表 / 存表达库」 | 按钮变「已存入」并禁用；去笔记本能看到新条目 | 保存会真写库；测完记得这是你的数据 |
| G-08 | 在任意聊天页发两条，按 F5 | 消息还在；输入框、随手查结果、当前评估会没 | 具体见第 6 节 |
| G-09 | 开两个标签各操作一次 | 能正常用；最后写入的覆盖前一个 | 已知限制，不修 |
| G-10 | 点任意带「重新开始」的聊天页侧栏底部按钮 | 先弹确认框；取消什么都不变；确认才清空 | 各页文案略有不同，机制一致 |

### 5.3 背单词（W）

| 编号 | 操作 | 预期 | 边界 |
| --- | --- | --- | --- |
| W-01 | 侧栏「📅 设置考试计划」 | 弹窗有目标分 ±、考试日期、自动安排开关；保存后 toast，侧栏显示剩余天数和每天约几个 | 可以不设日期，回到手动每日新词 |
| W-02 | 改起始难度、勾话题 | 立即生效并记住；今日学习上方的范围说明跟着变 | 筛选太严会提示没有可学的词 |
| W-03 | 关闭自动安排，拖每日新词 | 只影响新词数量，不影响到期复习 | 开了自动计划且设了日期时，滑杆消失 |
| W-04 | 点「开始今日学习」 | 进入答题，顶部「第 1 / N 个」；队列 = 到期复习 + 新词，上限 60 | 没有词可学会给黄色提示 |
| W-05 | 新词第一次出现 | 给英文选中文；4 个选项；不选提交会提示 | — |
| W-06 | 同一个词第二次出现 | 给中文选英文 | — |
| W-07 | 第三次起 | 例句挖空 + 输入框；拼写比较忽略空格/连字符/撇号 | 空着提交会提示 |
| W-08 | 每题答完点四档评分 | 进入下一题；不同档影响下次到期；忘了当天重来 | 评分按钮必须点，不点不会自动下一题 |
| W-09 | 点「只复习到期（N）」 | 只练到期词，不掺新词 | 没有到期时按钮灰 |
| W-10 | 点「巩固已学（10 个）」 | 从学过的词里挑最弱 10 个，打乱顺序 | 没背过词时禁用 |
| W-11 | 答完一轮 | 显示今日新词/复习/累计已学；有「再来一轮」 | 没词时会提示暂时没有要练的词 |
| W-12 | 切到「已背过」 | 三个指标、搜索、状态筛选；每条可展开看复习信息、听发音、移出 | 列表最多最近 100 条；移出**不退**当天新词额度 |
| W-13 | 点「🔊 听发音」 | 播放；缓存 mp3 在 `audio_records/`，第二次更快 | edge-tts 需要联网 |

### 5.5 严肃话题（S）

| S-08 | 侧栏「进入帮助会话」 | 跳到「老师帮帮我」，能看到当前考题 | 见 HP 节 |

### 5.6 讲个故事（P2）

| 编号 | 操作 | 预期 | 边界 |
| --- | --- | --- | --- |
| P2-01 | 进页面 | 自动生成 Cue Card；刷新/重启后还是同一张 | 生成失败用内置题库兜底 |

### 5.7 笔记本（N）

| 编号 | 操作 | 预期 | 边界 |
| --- | --- | --- | --- |
| N-01 | 单词 / 词组 → 复习 | 显示今天待复习 N 个、词库共 M 个；开始复习走三阶段 | 没有到期时按钮禁用 |
| N-02 | 单词 / 词组 → 单词表 | 四个指标；新增表单；搜索、排序、标签筛选；每条可修改/删除 | 删除就地展开确认；新增不去重 |
| N-03 | 表达 → 表达库 / 复习 | 填中文意图 + 地道说法；复习先给中文，点「显示地道说法」自测 | 表达是另一套间隔（1→3→7→14→28…，上限 120 天，21 天算掌握） |
| N-04 | 仓库 → 新增便签条 | 保存后标题可自动生成；按日期归档；能编辑、删除、导出 | 标题生成失败会留空或截取正文 |
| N-05 | 侧栏「补全缺失的翻译/词性/标签/例句」 | 跑完提示补全 N 条或没有需要补全的 | 会真调模型，旧条目多时慢 |
| N-06 | 修改或删除一个已在备课本/计划里的词 | 备课本和计划里的标签跟着改；删掉后计划点不会继续练旧词 | 这个同步是新链路，重点看 |
| N-07 | 从工作台「去巩固 / 去复习」进来 | 前者落单词复习，后者落表达 | 落点由工作台预置的 `session_state` 决定 |

### 5.8 雅思老师（T）

| 编号 | 操作 | 预期 | 边界 |
| --- | --- | --- | --- |
| T-01 | 第一次进入（没有计划） | 侧栏显示「还没有本课计划」；备课本有候选时出现「从备课本生成计划」 | 空计划 + 空备课本不会自动生成 |
| T-02 | 侧栏「➕ 我想练」加一个点 | 出现确认卡；确认后进备课本，也能进当前计划 | 空输入会提示先写一个概括 |

| T-04 | 在聊天框说「我想练 / 开始练」 | 老师先出题，说明练哪个点；输入框提示变化；侧栏计划变「训练中」 | 训练**只**由这类意图触发，普通聊天不会自动开始 |
| T-05 | 用英文完整作答 | 老师给具体反馈（哪里弱、怎么改、巩固清单）；必要时追问同一题 | 打勾由独立裁判判定；嘴上夸了但没用上点，不会打勾 |
| T-06 | 聊几轮后点「🔍 强制检测是否完成」 | 让裁判重看整场，补齐漏判；计划点消失或计划变「已完成」 | 没有手动打勾/撤销入口 |
| T-07 | 展开「🩹 待整理知识点」 | 列出错误和次数；「加入备课本」→ 进候选池并移除；「删除」只删掉 | 不点就一直躺着 |
| T-08 | 展开「📚 备课本」 | 显示候选、来源（弱词 / 笔记本 / 用户请求） | 表达库不再进备课本 |
| T-09 | 只发一个英文词或短语（≤5 词） | 返回「📖 词典讲解」卡片：音标、词性、释义、用法、搭配、例句，带发音 | 一两次模型调用 + 逐条 TTS，稍慢 |
| T-10 | 侧栏「🔄 重新开始聊天」 | 弹确认框；确认后清空对话和训练状态 | **计划、备课本、学习档案、今日进度都保留** |
| T-11 | 看侧栏「关于你」 | 记你的个人信息；训练中只读不写 | 「英语学习档案」面板已隐藏，但后台仍更新 `teacher_memory.json` |
| T-12 | 计划完成后再次打开老师页 | 当天第一次会自动更新下一课；备课本为空则不反复调模型 | 也可以手动「更新计划」 |

## 7. 已知边界（看到别当 bug）

1. **单用户、单进程**：两个标签同时写同一份 JSON 时，最后写入的覆盖前一个。
2. **输入方式不统一**：练习三页（严肃话题 / 自由聊天 / 讲个故事）是多行输入 + 提交按钮；
   老师、查资料、帮助和娱乐页是回车发送。
3. **娱乐四页**没有语音输入，也不能编辑已发消息；说错了只能重发一条。
4. **老师训练**只由「我想练 / 开始练 / 换点」触发，普通聊天不会自动进入；
   计划点由裁判判定，没有手动打勾。
5. **讲个故事空内容点提交没有任何提示**，像按钮失灵，其实直接 return。
6. **语音识别固定按英文跑**：说中文也会被当英文识别，结果可能很怪。
7. **三套间隔重复**：背单词、笔记本词条、表达库各有一套，统计不能混看。
8. **老师侧栏的「英语学习档案」已隐藏**，但后台仍每课更新 `teacher_memory.json`；
   要看直接打开文件。
9. **「老师帮帮我」没有工作台入口**，只能从严肃话题或讲个故事侧栏进入。
10. **移出已背过**只删记录，不退当天新词额度。
11. **AI 不是考官**：纠错、改写、评分和范文只作练习参考，不代表官方评分。

## 8. 自动化已经覆盖了什么

仓库里有 **20 个测试文件、322 个 `unittest` 用例**，不联网、不花钱：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

| 文件 | 覆盖 |
| --- | --- |
| `test_core.py` | 存储/备份、LLM JSON 容错、题卡清洗、SRS、音频清理 |
| `test_pages.py` | 用 Streamlit `AppTest` 真渲染每个页面，走发送/加点/训练/刷新恢复 |
| `test_tutor_*` / `test_plan_judge` / `test_prep_book` / `test_teacher_memory` | 老师链路的计划、裁判、表达层、记忆 |
| `test_help_*` / `test_part2_card` / `test_notebook_sync` / `test_exam_state` | 帮助会话、题卡持久化、笔记本同步、考官状态 |
| `test_chat_history.py` | 聊天记录的保存、恢复、上限、独立清空 |

手工测试的价值集中在四类自动化测不到的东西：

1. **模型输出质量**：纠错是不是真的、范文好不好、老师讲课像不像人。
2. **真实语音链路**：麦克风权限、Whisper 准不准、edge-tts 好不好听。
3. **浏览器行为**：刷新、多标签、自动播放被拦、切页不断音。
4. **视觉与文案**：排版挤不挤、按钮名对不对、状态提示看不看得懂。
