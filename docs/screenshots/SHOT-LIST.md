# 截图清单

> 这些图只用于 README 和 `docs/`，不放用户真实数据。
> 拍完把文件放进 `docs/screenshots/`，文件名保持下表一致即可。

## 通用规格

- **尺寸**：1440×900 或 1600×1000，浏览器缩放 100%。
- **主题**：浅色（App 默认主题），不要开深色模式或浏览器阅读模式。
- **范围**：只截 App 页面，不带浏览器地址栏、书签栏、Windows 标题栏。
- **一致性**：所有图用同一个窗口宽度，方便 README 表格对齐。
- **隐私**：用测试数据；不要出现真实姓名、API key、私人聊天、心理咨询内容。
- **格式**：PNG，单张尽量 < 800 KB；文字要能看清，不要过度压缩。
- **构图**：侧栏保留「工作台 / 音量 / 随手查」三块，能体现这是同一个 App。
